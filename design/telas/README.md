# HTML das telas do Minhas Compras

Estes são os **60 HTMLs finais exportados do Google Stitch**, organizados em uma pasta por tela ou estado. Cada pasta contém `index.html`, `preview.png` e `REFERENCIA.md` com o vínculo à implementação Flutter e o ID no Stitch.

## Implementação no Flutter

As 60 referências deste inventário possuem implementação documentada em `IMPLEMENTACAO.md` na respectiva pasta. A última etapa implementou a tela 60 e revisou o fluxo 59 → 60 em paralelo, com 49 testes aprovados e análise estática limpa. As diferenças funcionais e decisões constam nos documentos de cada tela; a revisão do fluxo financeiro está em [REVISAO_FLUXO_FINANCAS.md](../REVISAO_FLUXO_FINANCAS.md).

Os arquivos HTML são mockups visuais: ações e dados reais continuam implementados no Flutter. Para a renderização completa do HTML, é necessária conexão com a internet para carregar Google Fonts e Tailwind CDN usados pelo exportador do Stitch.
