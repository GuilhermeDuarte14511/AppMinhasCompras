## Critérios de fidelidade

- Somente dados disponíveis no modelo e ações presentes no fluxo atual devem ser implementados.
- Estados condicionado por autenticação, integração ou dados reais não aparecem simultaneamente no app.
- Produtos, preços e pessoas mostrados nas capturas são exemplos visuais; não são conteúdo salvo.
- O projeto Flutter tem mudanças locais anteriores a este redesign, que foram preservadas.
